# Linux Server Infrastructure Lab

VMware Workstation Pro와 Ubuntu Server 24.04 LTS를 활용한 Linux 서버 구축 및 운영 실습 포트폴리오입니다.

## 1. 프로젝트 개요

**목적**

시스템 엔지니어 및 인프라 엔지니어에게 필요한 Linux 서버 구축, 네트워크 설정, 스토리지 관리, 사용자 및 접근 권한 관리 역량을 실습을 통해 습득하고 검증하는 것을 목표로 합니다.

**실습 환경**

| 구분 | 환경 |
|---|---|
| 가상화 플랫폼 | VMware Workstation Pro |
| 운영체제 | Ubuntu Server 24.04 LTS |
| CPU | 2 vCPU |
| 메모리 | 3GB |
| 가상 디스크 | 30GB |
| 주요 기술 | Linux, LVM, SSH, VMware Networking, chmod, chown, SGID |

## 2. 시스템 구성 및 실습 내용

### 01. VMware 가상 서버 구축
- Ubuntu Server 24.04 가상머신 생성 및 설치
- CPU, 메모리, 가상 디스크 리소스 설정
- 가상머신 스냅샷 생성 및 복원 테스트

### 02. Linux 스토리지 관리
- LVM 구조 확인
- 논리 볼륨 및 파일시스템 확장
- 루트 파일시스템 용량 약 14GB → 28GB 확장

### 03. 가상 네트워크 구성
- NAT, Bridged, Host-only 네트워크 방식 실습
- 가상 NIC 구성 및 IP 주소 확인
- 네트워크 연결 상태 점검

### 04. SSH 원격 접속
- SSH 기반 원격 서버 접속
- 가상 네트워크 환경에서 접속 확인

### 05. Linux 사용자 및 접근 권한 관리
- 사용자 및 그룹 생성과 관리
- sudo 권한 부여 및 회수
- chmod, chown을 이용한 파일 권한 설정
- devteam 그룹 및 공유 디렉터리 구성
- SGID를 이용한 파일 그룹 상속
- 그룹 외 사용자 접근 차단 테스트
- sudo 관리자 권한 접근 검증

## 3. 주요 실습 검증 결과

**LVM 확장**

루트 논리 볼륨 및 파일시스템을 확장하여 저장 공간 증가를 확인했습니다.

**SGID 그룹 상속**

`/srv/devteam` 디렉터리에 SGID를 설정하고, developer1 사용자가 생성한 파일의 소유 그룹이 devteam으로 지정되는 것을 확인했습니다.

**접근 권한 검증**

일반 사용자 권한으로 접근했을 때 `Permission denied`가 발생하고, sudo 관리자 권한으로 접근하면 파일 내용을 정상적으로 읽을 수 있음을 확인했습니다.

## 5. 프로젝트를 통해 학습한 내용

Linux 서버의 사용자·그룹·파일 권한 구조를 이해하고, VMware 환경에서 서버 운영에 필요한 기본 관리 작업을 직접 수행했습니다.

특히 권한 설정 이후 실제 사용자 계정으로 접근 테스트를 진행하여, 설정값뿐 아니라 접근 제어의 동작 결과까지 검증했습니다.

향후 실습별 상세 명령어, 설정 과정, 검증 화면 및 문제 해결 내용을 문서화할 예정입니다.

## 6. 네트워크 구성 및 통신 검증 화면

![네트워크 검증 결과](./network-verification.png)

`ip -br addr` 명령어로 Host-only 및 NAT
인터페이스의 IP 주소를 확인하고,
`ip route` 명령어로 기본 게이트웨이가
NAT 인터페이스에 설정된 것을 검증했다.

또한 `ping -c 4 8.8.8.8` 명령어를
실행하여 패킷 손실률 0%로
외부 IP 통신에 성공했다.
