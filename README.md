# Linux Server Infrastructure Lab

VMware Workstation Pro와 Ubuntu Server 24.04 LTS를 활용하여 Linux 서버 구축부터 스토리지, 네트워크, 접근 권한, 프로세스, 서비스 및 로그 관리까지 실습한 **시스템·인프라 엔지니어 포트폴리오**입니다.

## 1. 프로젝트 개요

### 프로젝트 목적

Linux 서버 운영에 필요한 기본 관리 역량을 습득하고, 실제 명령어 실행과 검증 결과를 GitHub에 문서화하는 것을 목표로 진행했습니다.

### 실습 환경

| 항목 | 환경 |
|---|---|
| 가상화 플랫폼 | VMware Workstation Pro |
| 운영체제 | Ubuntu Server 24.04 LTS |
| CPU | 2 vCPU |
| 메모리 | 3GB |
| 가상 디스크 | 30GB |
| 원격 관리 | SSH |
| 주요 기술 | Linux, LVM, VMware Networking, SSH, ACL, SGID, systemd, journalctl |

## 3. 주요 실습 검증 결과

### LVM 스토리지 확장

루트 논리 볼륨과 파일시스템을 약 14GB에서 28GB로 확장하고 실제 저장 공간 증가를 검증했습니다.

### 사용자 및 파일 접근 권한 관리

사용자별 접근 권한을 설정하고 Permission denied 발생 여부 및 sudo 권한을 통한 접근 가능 여부를 확인했습니다.

### SGID 및 ACL 권한 관리

그룹 공유 디렉터리에 SGID를 적용하여 새로 생성한 파일의 그룹 상속을 확인하고 ACL을 이용한 세부 권한 설정을 실습했습니다.

### 프로세스 관리

백그라운드 프로세스를 생성한 후 PID를 확인하고 종료 신호를 전송하여 정상 종료 여부를 검증했습니다.

### 서비스 및 로그 분석

systemctl을 통해 SSH 서비스의 active (running) 상태를 확인하고 journalctl을 통해 서비스 시작·종료 및 SSH 로그인 성공 기록을 분석했습니다.

실시간 로그 모니터링 중 새로운 SSH 접속 이벤트가 기록되는 것을 확인했습니다.
